## 1. 개요

천상(Cheonsang)은 마인크래프트 오버월드의 하늘을 실제 천구로 바꾸는 Fabric 모드입니다. 관측 위치(위도·경도)와 날짜·시각에 따라 별·해·달·행성·심원천체의 위치와 밝기를 계산하고, 대기·하늘 밝기·빛공해·망원경 광학 조건을 거쳐 화면에 그립니다. 별의 위치와 등급은 HYG v4.1, Tycho-2, Gaia DR3 카탈로그에서 가져오고, 해·달·행성의 위치는 천체역학 계산식으로 구합니다.

게임 언어가 한국어이면 화면·명령 응답·정보 카드가 한국어로, 그 밖의 언어이면 영어로 표시됩니다.

## 2. 설치

### 2.1 요구 사항

| 항목 | 요구 사항 |
| --- | --- |
| Minecraft | Java Edition 26.3 |
| 모드 로더 | Fabric Loader 0.20.1 이상 |
| Java | 25 이상 |
| 필수 모드 | Fabric API, Fabric Language Kotlin |
| 선택 모드 | Mod Menu (모드 목록에서 설정 화면 열기) |
| 함께 쓸 수 없음 | Iris (셰이더 모드). 함께 설치하면 게임이 시작되지 않음 |

개발과 시험에 쓴 판은 Fabric API 0.165.0+26.3, Fabric Language Kotlin 1.14.2+kotlin.2.4.21입니다.

### 2.2 설치 순서

1. Fabric 설치 프로그램으로 Minecraft 26.3용 Fabric Loader(0.20.1 이상)를 설치합니다.
2. 게임 폴더의 `mods` 폴더에 Fabric API와 Fabric Language Kotlin jar를 넣습니다.
3. 천상 본체 jar(`cheonsang-2.0.1.jar`, 111.4 MB)를 `mods` 폴더에 넣습니다. 이전 버전의 cheonsang jar가 있으면 지웁니다.
4. 필요하면 Mod Menu와 확장팩을 같은 폴더에 넣습니다.
5. Fabric 프로필로 게임을 실행합니다.

### 2.3 확장팩 cheonsang-extra

확장팩 `cheonsang-extra-1.0.1.jar`(434.0 MB)는 선택 사항이며 본체와 같은 `mods` 폴더에 넣습니다. 본체의 모든 기능은 확장팩 없이 작동합니다.

| 항목 | 본체만 | 확장팩 추가 |
| --- | --- | --- |
| 망원경 별 | 2,409,260개, 표시 한계 13.0등 | Gaia DR3 별 32,061,510개 추가, 표시 한계 15.2등 |
| 맨눈 은하수 | 4K (망원경 확대 12K) | 16K·32K 조각 (보이는 부분만 불러옴) |
| 달 지도 | 최대 4K | 8K |
| 심원천체·관측 스케치 | 모두 포함 | 변화 없음 |

옛 Gaia 별 팩(`cheonsang-stars-*.jar`)은 확장팩과 같은 파일을 담고 있으므로 빼도 됩니다. 같이 있어도 문제는 없습니다. 설치된 팩의 상태는 천상 설정 화면 아래에 표시됩니다.

장노출(사진) 모드는 별도의 포토팩(`cheonsang-ultra`)이 있어야 켜집니다. 2.0.1 배포 묶음은 본체와 cheonsang-extra로 구성되며 포토팩은 포함되지 않습니다. 포토팩이 설치되어 있으면 그대로 동작합니다.

### 2.4 서버 설치

멀티플레이 서버에서는 서버의 `mods` 폴더에 천상 본체, Fabric API, Fabric Language Kotlin을 넣습니다. 서버와 접속하는 모든 사람이 같은 2.0.1을 설치해야 합니다. 확장팩은 화면 표현용이므로 각 클라이언트에만 넣으면 됩니다.

서버에 천상이 없어도 클라이언트 단독으로 하늘이 작동합니다. 이 경우 각자 설정 화면에서 정한 날짜와 위치(기본 2026-08-11, 0° 0°)로 하늘이 보입니다.

## 3. 처음 실행

### 3.1 새 월드의 기본 하늘

새 월드는 2026-08-11 06:00, 위도 0°·경도 0°에서 시작합니다. 압축률은 1.0(실제 속도)입니다. 다음 날인 8월 12일에는 개기일식, 페르세우스자리 유성우 극대, 그믐이 겹치고, 8월 28일에는 부분월식이 있습니다. 8월 12일 개기일식의 식 최대 지점은 약 65°N 25°W입니다.

이전 버전에서 쓰던 월드는 저장된 날짜·위치를 그대로 이어 씁니다.

### 3.2 시간과 위치의 기본 규칙

| 항목 | 규칙 |
| --- | --- |
| 날짜·시각의 흐름 | 월드에 하나. OP가 `/cele set`, `/cele rate`로 정함 |
| 관측 위치 | 사람마다 다름. 처음에는 월드 기본 위치(`/cele set` 값)이고, `/cplace`로 자기 하늘만 바꿈 |
| 마크 시계 | 내 관측 위치의 지방평균시. 경도 0°이면 세계시(UTC)와 같음 |
| 해 남중 | 12:00에서 균시차만큼(최대 약 ±16분) 어긋남 |
| 경도 변경 | 마크 시계와 낮밤은 그대로이고 세계시만 경도만큼 밀림 |
| 압축률 | 마크 하루 동안 하늘이 며칠 흐르는지. 1.0이면 마크 하루에 하늘도 하루 |

화면의 낮밤(하늘색·안개·땅에 비치는 빛)은 기본적으로 천상의 실제 해 고도를 따릅니다. 몹 생성과 잠자기는 바닐라의 10분 낮·10분 밤 규칙을 그대로 따릅니다(바꾸는 방법은 8.3절).

### 3.3 처음 해 볼 일

1. 밤이 되면 `/cwhen`으로 오늘 밤 볼거리를 확인합니다.
2. 천체망원경을 만듭니다(6.1절).
3. 망원경을 들고 우클릭해 켠 뒤 마우스 휠로 배율을 올립니다. 처음 켤 때 조작 안내가 한 번 나옵니다.
4. `/cfind 목성` 등으로 천체를 찾고, 좌클릭으로 골라 정보 카드를 봅니다.
5. 조작 설정에서 "천상 설정" 키를 지정해 둡니다(기본값 없음).

## 4. 화면 구성

| 요소 | 위치·내용 |
| --- | --- |
| 하늘 | 별, 은하수, 해·달·행성, 심원천체, 별자리 선·이름(망원경 화면), 유성, 오로라 |
| 조준선 | 망원경 화면 가운데 (설정에서 끌 수 있음) |
| 광학 줄 | 망원경 사용 중 왼쪽 아래 한 줄: 구경 · 대물 초점 · 접안 · 배율 (예: 80mm · 초점 560mm · 접안 25mm · ×22) |
| 정보 카드 | 선택한 천체의 정보. 기본 위치는 왼쪽 위, 투명도 69% |
| 선택 표시 | 선택한 천체 둘레의 원. 추적 중이면 카드 제목에 [추적] |
| 각거리 표시 | 보라색 원과 잇는 선, 카드 끝 줄의 "각거리 → 이름" |
| 방향 화살표 | `/cfind` 실행 후 60초 동안. 찾으면 꺼짐 |
| 오류 표시 | 화면 위의 "천상 ○○ 오류" (11절) |

광학 줄은 핫바와 왼손 칸에 가리지 않도록 자리를 잡습니다. 화면 왼쪽의 빈 폭이 좁으면 글씨를 자동으로 줄이고(최소 절반 크기), 그래도 들어가지 않으면 체력·방어 칸 위로 올려 표시합니다.

### 4.1 정보 카드 내용

| 대상 | 표시 항목 |
| --- | --- |
| 공통 | 방위·고도(대기 굴절 포함), 적경·적위(오늘 날짜 기준), 출·남중(고도)·몰 |
| 별 | HIP·HD 번호, 분광형, 등급, 절대등급, 거리 |
| 이름 붙은 유명 별 | 등급, 거리, 한 줄 설명 |
| 깊은 별 (9등보다 어두운 별) | 등급, 색, 위치, 출몰 (카탈로그 번호 없음) |
| 행성 | 등급, 지름, 위상, 지구·해까지 거리, 해와의 각거리 |
| 달 | 위상, 달 나이, 지름, 거리 |
| 달 지명 | 종류, 지름, 달 위도·경도, 그날 칭동 |
| 해 | 지름, 거리 |
| 성운·성단·은하 | 종류(은하는 드보클레르 형태), NGC 번호, 등급, 크기, 거리 |
| 위성 | 등급, 위치, 모행성 뒤에 있으면 "현재 가려짐" |

출몰 줄은 출·몰(해는 일출·일몰, 달은 월출·월몰)로 표기하며, 해당하는 경우 "지지 않음", "이 위도에서 뜨지 않음", "종일 떠 있음", "종일 뜨지 않음"으로 나옵니다. 방위·고도, 적경·적위, 출몰 줄은 설정 화면에서 각각 숨길 수 있습니다.

## 5. 조작키

### 5.1 천상 전용 키

조작 설정의 "기타" 분류에 있으며 모두 바꿀 수 있습니다.

| 키 이름 | 기본값 | 동작 |
| --- | --- | --- |
| 망원경 표시 바꾸기 | N | 표시 순환: 전부 → 선만 → 이름만 → 끄기 |
| 천체 추적 (누른 채 좌클릭) | 왼쪽 Alt | 누른 채 좌클릭하면 선택과 추적 고정 |
| 대물 구경 (누른 채 휠) | 왼쪽 Shift | 누른 채 휠을 돌리면 구경 변경 |
| 천상 설정 | 없음 | 천상 설정 화면 열기 |

N 키로 별자리 선과 이름을 끄고 관측하면 실제 접안렌즈 시야에 가까워집니다.

### 5.2 망원경 조작

| 조작 | 동작 |
| --- | --- |
| 우클릭 | 망원경 켜기·끄기. 켤 때마다 ×1, 구경 80mm에서 시작. 손에서 놓으면 꺼짐 |
| 마우스 휠 | 접안렌즈 변경: ×1 → 40 · 32 · 25 · 20 · 15 · 12 · 9 · 7 · 5 · 4 · 3mm |
| 대물 구경 키 + 휠 | 구경 변경: 50 · 60 · 70 · 80 · 90 · 102 · 114 · 127 · 150 · 200 · 254 · 305mm |
| 좌클릭 | 화면 가운데 천체 선택 (원 표시와 실시간 정보 카드) |
| 웅크리기 키(Shift) + 좌클릭, 또는 빈 하늘 좌클릭 | 선택 해제 |
| 추적 키 + 좌클릭 | 선택과 추적 고정. 그 천체가 화면 가운데에 계속 머묾 |
| Ctrl + 좌클릭 | 천체를 선택한 상태에서 화면 가운데 천체까지의 각거리 측정 |

추적은 추적 키 + 좌클릭을 다시 하거나, Shift + 좌클릭을 하거나, 마우스를 크게 움직일 때 풀리고, 천체가 지평선 아래로 지면 자동으로 풀립니다. 채팅이나 다른 화면을 열어도 추적은 계속됩니다. 설정 화면이 열려 있으면 휠 입력은 그 화면으로 갑니다.

## 6. 천체망원경

### 6.1 만들기

작업대에서 모양이 정해진 조합법으로 만듭니다. 크리에이티브 모드에서는 "도구 및 유틸리티" 탭에 있습니다.

| | 왼쪽 | 가운데 | 오른쪽 |
| --- | --- | --- | --- |
| 윗줄 | | 유리판 | |
| 가운뎃줄 | | 망원경(spyglass) | |
| 아랫줄 | 철 주괴 | 철 주괴 | 철 주괴 |

아이템 이름은 "천체망원경"(영어 Telescope)입니다. 3D 굴절망원경 모델로 그려지며, 확대하면 접안부를 눈에 대는 자세가 됩니다. 멀티플레이에서는 다른 사람 화면에도 이 자세가 보입니다.

### 6.2 광학 값

| 항목 | 값 |
| --- | --- |
| 초점비 | f/7 고정 (대물 초점거리 = 구경 × 7) |
| 배율 | 대물 초점거리 ÷ 접안렌즈 초점거리. 최대 305mm + 3mm = ×712 |
| 한계등급 | 맨눈 한계 + 구경 이득. 맨눈 6.5등 기준으로 7.7 + 5·log10(구경 cm)과 같음. 기본 설정(맨눈 6.0)에서 80mm 11.7등, 305mm 14.6등. 하늘 밝기·암적응 상태만큼 더 깎임 |
| 한계등급 상한 | 본체만 13.0등, 확장팩 설치 시 15.2등 |
| 별 상 크기 | 회절 반지름(138″/D, D는 mm)과 시상 1.5″를 합친 크기. 근접 쌍성이 구경에 따라 갈라짐 |
| 출사동 | 7mm보다 크면 그만큼 어둡게 |
| 과배율 | 배율이 구경(mm) × 2를 넘으면 상이 흐려짐 (배율은 막지 않음) |
| 시야 | 둥근 시야, 약한 시상 흔들림 |

| 구경 | 대물 초점 | 배율 범위 | 한계등급 (맨눈 6.0 / 6.5) | 기준 최대 배율 |
| --- | --- | --- | --- | --- |
| 50mm | 350mm | ×8.8 \~ ×117 | 10.7 / 11.2 | ×100 |
| 80mm (기본) | 560mm | ×14 \~ ×187 | 11.7 / 12.2 | ×160 |
| 127mm | 889mm | ×22 \~ ×296 | 12.7 / 13.0 | ×254 |
| 305mm | 2,135mm | ×53 \~ ×712 | 14.6 / 15.1 | ×610 |

127mm와 305mm의 맨눈 6.5 기준 값 가운데 13.0등을 넘는 부분은 확장팩이 있어야 나타납니다.

f/7 망원경에서 접안렌즈별 출사동은 구경과 관계없이 다음과 같습니다.

| 접안렌즈 (mm) | 40 | 32 | 25 | 20 | 15 | 12 | 9 | 7 | 5 | 4 | 3 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 출사동 (mm) | 5.7 | 4.6 | 3.6 | 2.9 | 2.1 | 1.7 | 1.3 | 1.0 | 0.7 | 0.6 | 0.4 |

별 상 반지름은 50mm에서 1.88″, 80mm에서 1.37″, 127mm에서 1.11″, 305mm에서 0.94″입니다. 두 별 사이 간격이 별 상보다 충분히 벌어지면 화면에서 저절로 둘로 갈라집니다. 이 값들이 뜻하는 바는 부록 A.2에서 설명합니다.

### 6.3 배율에 따라 보이는 것

| 배율 | 보이는 것 |
| --- | --- |
| ×1 | 평소 시야, 조준선, 이름, 좌클릭 선택 |
| ×10 이상 | 은하수, 별자리 선, 성운 빛무리, 배경 별 |
| ×50 이상 | 행성 원판, 달 전체, 성운·성단 빛무리, 은하 관측 스케치 (포토팩과 장노출 모드면 사진 45장이 겹침) |
| ×150 이상 | 행성 무늬, 토성 고리, 목성 위성, 토성 위성 7개, 달 크레이터와 지명 |

토성 위성 미마스(12.9등)는 305mm 근처가 한계입니다. 고배율에서도 별자리 선은 끝까지 그려집니다. ×700을 넘는 배율에서도 좌클릭으로 천체를 정확히 고를 수 있으며, 시리우스 B처럼 밝은 별 바로 옆의 어두운 짝별도 고를 수 있습니다.

### 6.4 찾기와 추적

`/cfind <이름> true`를 실행하면 그 천체로 시점이 돌아가고, 망원경을 들고 있으면 망원경이 켜지며 추적이 고정됩니다. 위성·행성·성운·성단·은하는 찾은 그 천체에 바로 고정되고, 별은 화면 가운데에서 고릅니다. 위성은 행성 뒤에 있어도 추적하며 "현재 가려짐"을 표시합니다. 천체가 지평선 아래에 있으면 시점을 돌리지 않습니다.

고배율에서는 시야가 좁아 대상이 금방 빠져나가므로, 저배율에서 찾은 천체를 추적 키 + 좌클릭으로 고정한 뒤 배율을 올리는 순서가 편합니다.

## 7. 명령어 레퍼런스

모든 명령에서 명령 낱말(set, solar, total 등)은 영어만 씁니다. 천체 이름은 한국어·영어 모두 됩니다. 위도는 북쪽이 +, 경도는 동쪽이 +입니다. 소수점은 점(.)으로 씁니다.

#### /cwhen

```
/cwhen
/cwhen <천체>
/cwhen solar <total|annular|partial>
/cwhen lunar <total|partial|penumbral>
/cwhen meteor [이름]
/cwhen full
/cwhen new
/cwhen conj
/cwhen next
```

내 화면에서만 계산하는 명령이므로 서버에 천상이 없어도 쓸 수 있습니다. 계산은 별도 스레드에서 돌며("계산 중…"), 같은 명령을 다시 치면 앞 계산이 취소됩니다.

| 형식 | 결과 |
| --- | --- |
| `/cwhen` | 오늘 밤: 일몰·일출·완전히 어두운 시간, 달 위상·월출몰·달 없는 시간, 보이는 행성, 높이 뜨는 밝은 성운·성단·은하 5개, 유성우. 맨눈 한계보다 어두운 천체에는 "(망원경)". 첫 줄 끝에 "여기 하늘 보틀" 값 |
| `/cwhen <천체>` | 그 천체를 가장 잘 보는 밤 한 줄 (날짜·시각·고도·방위, 달과 달 지명은 위상 %). 이름은 `/cfind`와 같음. 이름이 여럿 맞으면 "다른 후보" |
| `/cwhen solar <종류>` | 다음 일식. 식 최대 지점 위도·경도, 그곳 시각, 해 고도, 지속 시간, 띠 폭, 여기서 보이는 정도 |
| `/cwhen lunar <종류>` | 다음 월식. 반영·본영 시작, 개기, 최대, 끝 시각, 덮는 비율. 달이 떠 있으면 "여기서 보임"과 달 고도 |
| `/cwhen meteor [이름]` | 다음 유성우 극대. 복사점 고도, 시간당 예상 수, 달. 이름을 빼면 가장 가까운 유성우 |
| `/cwhen full` · `new` · `conj` | 다음 보름 · 삭 · 행성 근접 (내 관측 위치 기준) |
| `/cwhen next` | 다음 일식·월식·보름·삭·유성우·행성 근접을 한 줄씩 (일식·월식은 종류와 관계없이 가장 가까운 것) |

`/cwhen <천체>`의 판정 기준은 천체 고도, 하늘의 어둠(해 고도), 달빛, 한계등급 여유입니다. 그 위도에서 천체가 뜨지 않거나 너무 낮으면 잘 보이는 위도가 함께 제시됩니다.

인자 상세:

| 인자 | 값 |
| --- | --- |
| solar 종류 | total(개기), annular(금환), partial(부분). partial은 어디서도 개기·금환이 되지 않는 일식(NASA 분류). 혼성일식은 total과 annular 양쪽으로 찾힘 |
| lunar 종류 | total(개기), partial(부분), penumbral(반영) |
| meteor 이름 | QUA, LYR, ETA, PER, ORI, LEO, GEM 또는 한국어·영어 이름 |

`/cwhen solar`, `/cwhen lunar`만 치면 "종류 선택:" 줄이 나오고, 종류를 누르면 명령이 채워집니다.

찾는 범위: 별·성운·은하 1년, 행성·소행성·위성 3년, 달 60일, 달 지명 120일, 일식·월식 60년.

결과의 시각은 결과 위치의 지방평균시이며, [이동] 뒤 마크 시계에 보일 시각과 같습니다.

| 버튼 | 동작 |
| --- | --- |
| [위치] | 추천 위도로 `/cplace` (누구나, 내 하늘만) |
| [이동] | 천체 결과: 그 날짜·시각·장소로 `/cele set` (OP 전용, 월드 전체). 일식·월식·유성우 결과: `/cplace <위도> <경도>` (누구나, 내 하늘만, 날짜·시각은 그대로). 이미 0.5° 안이면 버튼 없음 |
| [다음] | 그다음 결과 |

예: `/cwhen M51`, `/cwhen 토성`, `/cwhen solar total`, `/cwhen lunar partial`, `/cwhen meteor PER`

#### /ctonight

`/cwhen`의 옛 이름으로 아직 실행되지만 자동완성에는 나오지 않습니다. `/cwhen`을 씁니다.

### 7.2 OP 명령 (권한 수준 2)

`/cele` 아래의 set, rate, realtime, reset은 OP 권한(게임 관리자, 권한 수준 2)이 필요합니다. 싱글플레이에서는 치트 허용 월드에서 쓸 수 있습니다. 명령 응답은 명령을 친 사람의 클라이언트 언어로 나옵니다.

#### /cele set

```
/cele set <년> <월> <일> <시> <분> <위도> <경도>
/cele set today
```

하늘의 날짜·시각(지방평균시)과 월드 기본 위치를 정합니다.

| 인자 | 범위 | 설명 |
| --- | --- | --- |
| 년 | −2999 \~ 2999 | |
| 월 | 1 \~ 12 | |
| 일 | 1 \~ 그달의 마지막 날 | |
| 시 | 0 \~ 23 | 적으면 월드 시각도 맞춤 |
| 분 | 0 \~ 59 | 시만 적으면 0분 |
| 위도 | −90 \~ 90 또는 장소 이름 | 장소 이름을 쓰면 경도는 적지 않음 |
| 경도 | −180 \~ 180 | 동 +, 서 − |

- 뒤쪽 인자는 생략할 수 있고, `~`는 지금 값을 유지합니다.
- 시·분을 적지 않으면 월드 시계는 그대로 두고 날짜만 바뀝니다.
- 날짜가 1800\~2050년 밖이면 응답 끝에 행성 오차 경고가 붙습니다.
- 위도·경도를 바꾸면 `/cplace`로 자기 위치를 정한 모든 사람의 개인 위치가 풀립니다. 날짜·시각만 바꾸면 유지됩니다.
- `/cele set today`는 오늘 날짜로 바꾸고 시각·위치는 그대로 둡니다.

예:

```
/cele set 2026 8 12 18 30 40.4 -3.7
/cele set ~ ~ ~ ~ ~ -33.9 151.2
/cele set 2026 8 12 ~ ~ seoul
```

#### /cele rate

```
/cele rate <압축률>
```

압축률을 0.01\~1000 사이로 정합니다. 1은 실제 속도로, 마크 하루(20분)에 하늘도 하루가 흐릅니다. 값을 키우면 계절과 별자리 변화가 빨라집니다. 응답에는 1년이 마크 며칠인지가 함께 나옵니다.

#### /cele realtime

```
/cele realtime
/cele realtime <도시>
/cele realtime off
```

리얼타임을 켜면 마크 하루가 현실 하루가 되고, 하늘은 그 도시의 위치와 현재 시각을 따릅니다. 도시를 생략하면 seoul입니다. 도시는 7.1절 장소 표에서 greenwich를 뺀 13곳입니다.

리얼타임이 켜져 있는 동안 `/cele set`, `rate`, `reset`은 막힙니다. 정보 카드와 `/cwhen`의 시각은 그 도시의 시계 시각으로 나옵니다. 침대로 밤을 넘겨도 5초 안에 현실 시각으로 돌아갑니다. 서버를 다시 켜도 유지됩니다. `/cele realtime off`는 켜기 전의 날짜·압축률·위치로 되돌립니다.

#### /cele reset

```
/cele reset
```

하늘을 기본값(2026-08-11 기준, 서버 설정의 압축률과 위치, 기본 0° 0°)으로 되돌립니다.

### 7.3 진단 명령

| 명령 | 동작 |

## 12. 알려진 제한

- 셰이더 모드(Iris)를 지원하지 않습니다.
- 서버 OP가 `/cele set`으로 위도·경도를 바꾸면 모든 사람의 `/cplace`가 풀립니다.
- 리얼타임이 켜진 월드에서 `/cplace`로 경도를 바꾸면 하늘의 세계시가 현실과 경도 차만큼 어긋납니다.
- 천상열차분야지도 별자리 289개를 담았으며, 현대 별과 대응시킬 수 없는 5개(천직·천묘·동구·군문·기부)와 명나라 때 더해진 남극 부근 별자리 23개는 들어 있지 않습니다.
- `/cwhen`의 보이는 정도는 고도·어둠·달빛만 고려하며 빛공해와 날씨는 보지 않습니다. 위성은 모행성 위치로 계산하고, 달 지명은 칭동을 무시합니다. 압축률이 1이 아닌 월드에서는 표시 시각이 어긋날 수 있습니다.
- 은하 관측 스케치는 화면에서 아주 작을 때 반짝일 수 있고, 아주 밝은 은하 핵은 납작하게 보입니다. M31처럼 큰 은하를 고배율로 크게 보면 흐립니다. M42 바깥 날개와 M27 몸통 모양은 사진 한계로 덜 뚜렷합니다. 1′보다 작은 행성상성운은 원판으로 그려집니다.
- 유성은 컴퓨터 시계를 따라 흐르며 게임의 시간 정지·압축률과 무관합니다.
- 화면 낮밤만 천상 해를 따르고, 몹 생성·잠자기는 바닐라를 따릅니다.
- 날씨, 구름, 대기 투명도 변화가 없습니다. 시상은 1.5″, 소광 계수는 고정입니다. 하늘 밝기는 천정 한 점의 값을 하늘 전체에 적용합니다.
- 렌즈 수차, 중앙 차폐, 투과율은 계산하지 않습니다. 암적응 회복 30초는 게임용으로 줄인 값입니다.
- 별 위치는 J2000 좌표에 세차만 적용하며 장동·광행차·고유운동은 반영하지 않습니다(Stellarium 대비 약 1′). 달은 물리칭동과 장동을 제외해 오차가 0.04° 안팎입니다.
- 행성 위치는 VSOP87D 축약 이론(진폭 3×10⁻⁶ rad 이상 1,259항)으로 계산합니다. 1800\~2050년 PyEphem 대조 최대 오차는 수성 4.3″, 금성 5.4″, 화성 12.6″, 목성 4.3″, 토성 3.8″, 천왕성 4.0″, 해왕성 2.4″이고, 기원전 1000년\~서기 3000년 전체에서 최대 약 2′입니다.
- 세레스·베스타와 토성 위성은 1900\~2050년 자료에 맞춘 것이어서 범위 밖에서는 정확도가 떨어지거나 표시되지 않습니다.
- 달력 범위는 기원전 2999년\~서기 2999년입니다.
- 15.2등보다 어두운 별은 은하수 영상에만 포함됩니다. 명왕성은 없습니다.

## 부록 A. 천문 관측 가이드

실제 천문 관측의 개념과 천상의 대응 기능을 함께 다룹니다. 망원경 조작은 5.2절, 광학 수치는 6.2절, 명령 문법은 7절을 따릅니다.

### A.1 관측 조건

#### A.1.1 한계등급과 하늘 밝기

한계등급(limiting magnitude)은 주어진 조건에서 볼 수 있는 가장 어두운 별의 등급입니다. 맨눈 한계등급(naked-eye limiting magnitude, NELM)은 하늘이 어둡고 눈이 충분히 적응한 상태에서 대략 6\~6.5등입니다. 등급은 로그 척도여서 5등급 차이가 밝기 100배에 해당하며, 1등급 차이는 약 2.512배입니다.

한계등급을 가장 크게 좌우하는 조건은 하늘 밝기(sky brightness)입니다. 하늘 밝기는 등/초각²(mag/arcsec²) 단위로 나타내며, 값이 클수록 어두운 하늘입니다. 빛이 전혀 없는 자연 하늘의 천정은 약 22등/초각²입니다.

천상은 대기광(airglow), 박명, 달빛, 빛공해, 황도광을 더해 하늘 밝기를 구하고, 이 값으로 한계등급을 깎습니다. 맨눈 한계의 기준값은 `client.json`의 `nakedEyeLimit`(8.2절)로 정합니다. 하늘 밝기에 의한 손실은 보름밤에 약 1.7등, 해 고도 −6°의 박명에서 약 5.4등입니다. 보름달이 뜬 밤에는 희미한 별과 은하수가 하늘에 묻힙니다.

#### A.1.2 빛공해와 Bortle 척도

Bortle 척도는 밤하늘의 어두움을 1(가장 어두운 하늘)부터 9(도심)까지 나눈 관측자용 척도입니다. 실제 관측에서는 도시에서 멀어질수록 은하수, 황도광, 희미한 성운이 차례로 드러납니다.

천상은 관측자 주변 ±64블록 범위에서 하늘이 트인 칸(하늘 빛 15)의 블록 빛을 표본으로 모아 Bortle 지수를 추정합니다. 횃불·등불 같은 광원이 많은 마을 옆에서는 하늘이 밝아지고 마을 쪽 지평선에 주황빛 돔이 생깁니다. 집 안이나 동굴 안의 불빛은 계산에 들어가지 않지만 창문으로 새는 빛은 들어갑니다. 현재 값은 `/cwhen` 첫 줄 끝의 "여기 하늘 보틀"로 확인합니다.

| Bortle | 천정 밝기 (등/초각²) | 맨눈 한계 (기본 6.0 기준) |
| --- | --- | --- |
| 1 | 21.9 | 6.0 |
| 3 | 21.4 | 5.8 |
| 5 | 20.0 | 5.2 |
| 7 | 18.5 | 4.3 |
| 9 | 17.5 | 3.7 |

관측지로는 마을에서 64블록 넘게 떨어진 곳, 또는 주변에 광원 블록이 없는 언덕이나 평원이 좋습니다. 관측소를 지을 경우 조명을 지붕 아래나 실내에 두면 하늘 밝기에 영향을 주지 않습니다.

#### A.1.3 암적응

사람 눈은 어두운 곳에 들어가면 동공이 넓어지고 망막 간상세포의 감도가 서서히 올라갑니다. 실제로는 20\~30분이 지나야 충분히 적응하며, 밝은 빛을 한 번 보면 적응이 곧바로 풀립니다. 관측자가 붉은 손전등을 쓰는 이유는 간상세포가 붉은빛에 둔감해 적응을 덜 해치기 때문입니다. 시야 중심에서 약간 비켜 보는 주변시(averted vision)를 쓰면 희미한 대상이 더 잘 보입니다.

천상의 암적응은 눈 위치의 블록 빛이나 손에 든 광원이 밝을 때 바로 풀리고, 어두운 곳에서 최대 30초에 걸쳐 회복됩니다. 최대 손실은 3등입니다. 관측 직전에 횃불을 들고 있었다면 손에서 내려놓고 잠시 기다린 뒤 관측을 시작합니다.

#### A.1.4 대기: 소광, 굴절, 반짝임, 시상

천체의 빛은 지평선에 가까울수록 두꺼운 대기를 지납니다. 그 두께를 대기량(airmass)이라 하며, 천정에서 1이고 고도 30°에서 약 2가 됩니다. 대기를 지나며 빛이 흡수·산란되어 어두워지는 현상을 소광(extinction)이라 합니다. 파장이 짧은 푸른빛이 더 많이 줄어들기 때문에 지평선 근처의 별은 어둡고 붉게 보입니다.

천상의 소광 계수는 V 0.172, B 0.30, R 0.09 등/대기량입니다. 대기 굴절로 지평선의 천체는 약 0.5° 떠 보이며, 해와 달은 지평선에서 위아래로 납작해집니다. 실제 관측에서도 대상이 높이 떠 있을 때(고도 30° 이상, 가능하면 남중 무렵) 관측하는 것이 기본 원칙입니다.

반짝임(scintillation)은 대기의 굴절률 요동 때문에 별빛의 세기가 빠르게 변하는 현상으로, 지평선 쪽에서 강합니다. 천상에서는 맨눈과 저배율에서 별이 깜빡이고 고배율에서는 사라집니다. 행성은 겉보기 원판이 있어 실제로도 덜 반짝입니다.

시상(seeing)은 망원경으로 본 상이 대기 흔들림 때문에 번지는 정도를 말하며, 별 상의 지름(초각)으로 나타냅니다. 중위도의 보통 관측지에서는 1\~3″ 정도입니다. 천상은 시상을 1.5″로 고정하고 고배율 화면에 약한 흔들림을 줍니다. 투명도(transparency)는 대기가 얼마나 맑은지를 뜻하며 시상과는 별개의 조건입니다. 천상에는 구름과 날마다 달라지는 투명도가 없습니다.

#### A.1.5 달빛과 박명

박명(twilight)은 해가 진 뒤에도 하늘이 밝은 시간으로, 해 고도에 따라 시민박명(−6°까지), 항해박명(−12°까지), 천문박명(−18°까지)으로 나눕니다. 해가 −18° 아래로 내려가야 하늘이 완전히 어두워집니다. 고위도 지방의 여름에는 해가 −18° 아래로 내려가지 않아 밤새 완전히 어두워지지 않습니다.

`/cwhen`은 그날의 "완전히 어두움" 시간과 "달 없는 어둠" 시간을 함께 알려 줍니다. 은하와 희미한 성운은 달 없는 어둠 시간에 관측하고, 달·행성·이중성처럼 밝은 대상은 달이 밝은 밤에 관측하는 식으로 계획을 나누면 한 달을 고르게 쓸 수 있습니다.

### A.2 망원경 광학의 원리

천상 망원경의 구경·접안렌즈 단계, 배율 범위, 한계등급, 출사동, 별 상 크기 값은 6.2절 표에 있습니다.

#### A.2.1 구경과 집광력

구경(aperture)은 대물렌즈의 지름입니다. 빛을 모으는 능력(집광력)은 구경의 제곱에 비례하므로, 구경이 두 배가 되면 네 배의 빛을 모읍니다. 망원경의 한계등급은 흔히 다음 근사식으로 나타냅니다.

m_lim = 7.7 + 5 log10(D / 1 cm)

이 식은 맨눈 한계 6.5등을 기준으로 한 경험식입니다. 천상은 맨눈 한계에 구경 이득을 더하는 방식으로 같은 결과를 내며, 기본 설정(맨눈 6.0등)에서는 0.5등 낮습니다. 실제 하늘 밝기와 암적응 상태만큼 다시 깎입니다.

#### A.2.2 배율과 접안렌즈

배율은 대물 초점거리를 접안렌즈 초점거리로 나눈 값입니다.

M = F / f

배율을 높인다고 해서 더 많은 것이 보이지는 않습니다. 쓸 만한 최대 배율은 경험적으로 구경(mm)의 약 2배이며, 그보다 높이면 상이 커지기만 하고 흐려집니다(빈 배율, empty magnification). 천상도 이 기준을 넘으면 상을 흐리게 합니다(6.2절 과배율).

#### A.2.3 출사동

출사동(exit pupil)은 접안렌즈 뒤로 나오는 빛다발의 지름으로, 구경을 배율로 나눈 값이며 접안렌즈 초점거리를 초점비로 나눈 값과 같습니다. 어두운 곳에서 사람 동공은 최대 약 7mm까지 열리므로, 출사동이 7mm보다 크면 빛 일부가 눈에 들어가지 못합니다. 반대로 출사동이 작아질수록 성운·은하처럼 넓게 퍼진 대상의 표면 밝기가 낮아집니다.

관측 현장에서 쓰는 대략의 기준은 다음과 같습니다. 접안렌즈별 출사동 값은 6.2절 표를 봅니다.

| 출사동 | 쓰임 |
| --- | --- |
| 4\~7mm | 넓게 퍼진 성운, 큰 산개성단, 은하수, 혜성. 대상 찾기 |
| 2\~3mm | 대부분의 은하와 구상성단, 작은 성운 |
| 1mm 안팎 | 행성상성운, 구상성단 중심부, 달 |
| 0.5\~0.7mm | 행성 세부, 근접 이중성 |

#### A.2.4 분해능

빛은 회절하기 때문에 별의 상은 작은 원반(에어리 원반, Airy disk)으로 맺힙니다. 에어리 원반 첫 어두운 고리의 반지름은 약 138″/D(mm)이며, 이 값을 두 별을 나눠 볼 수 있는 한계로 삼는 것이 레일리 기준(Rayleigh criterion)입니다. 관측자들이 경험으로 얻은 도스 한계(Dawes' limit)는 116″/D(mm)로 조금 더 작습니다.

천상은 회절 반지름 138″/D와 시상 1.5″를 합쳐 별 상의 크기를 정합니다. WDS 근접 쌍성의 반성 7,459개가 들어 있으며, 맨눈에서는 한 점이었던 카스토르, 미자르, 거문고자리 ε 등이 구경과 배율에 따라 분리됩니다.

구경이 커지면 분해능이 좋아지지만, 시상이 별 상 크기의 하한을 정하기 때문에 큰 구경에서는 이득이 줄어듭니다. 6.2절의 별 상 반지름에서 127mm와 305mm의 차이가 50mm와 127mm의 차이보다 작은 것도 같은 이유입니다.

### A.3 하늘에서 길 찾기

#### A.3.1 두 가지 좌표계

지평좌표계는 관측자 기준입니다. 고도(altitude)는 지평선에서 위로 잰 각이고, 방위각(azimuth)은 북쪽에서 동쪽으로 잰 각입니다. 같은 별이라도 시각과 장소에 따라 고도·방위가 달라집니다.

적도좌표계는 천구 기준입니다. 적경(right ascension, α)은 춘분점에서 동쪽으로 잰 각을 시간 단위로 나타내고, 적위(declination, δ)는 천구 적도에서 남북으로 잰 각입니다. 별의 적경·적위는 거의 변하지 않으므로 성도와 카탈로그는 이 좌표를 씁니다.

정보 카드(4.1절)에는 두 좌표가 함께 나옵니다. 설정 화면에서 적도 격자와 지평 격자(8.1절)를 켜면 두 좌표계를 하늘 위에서 직접 비교할 수 있습니다.

위도 φ인 곳에서 적위 δ인 천체의 남중 고도는 90° − φ + δ입니다(북반구, 천체가 천정 남쪽을 지날 때). 북극성의 고도는 그곳의 위도와 거의 같습니다. 적위가 −(90° − φ)보다 낮은 천체는 그 위도에서 떠오르지 않습니다. 정보 카드의 출몰 표기에 "이 위도에서 뜨지 않음", "지지 않음"이 나오는 것도 이 관계에서 비롯됩니다.

#### A.3.2 각거리 어림

팔을 쭉 뻗었을 때 새끼손가락 폭은 약 1°, 주먹 폭은 약 10°, 엄지와 새끼손가락을 편 한 뼘은 약 20°입니다. 보름달의 지름은 약 0.5°입니다. 북두칠성 국자 끝 두 별(두베와 메라크) 사이는 약 5°입니다.

천상에서는 각거리 측정(5.2절, Ctrl + 좌클릭)으로 손으로 어림한 값과 측정값을 비교할 수 있습니다.

#### A.3.3 별자리 찾기와 별 따라가기

별자리는 밝은 별로 이루어진 기준 도형에서 시작해 이웃 별자리로 넓혀 가며 익힙니다. 대표적인 길잡이는 다음과 같습니다.

- 북두칠성 국자 끝 두 별(메라크→두베)을 이은 선을 약 5배 늘이면 북극성에 닿습니다.
- 북두칠성 손잡이의 곡선을 따라가면 목동자리 아르크투루스, 다시 이어가면 처녀자리 스피카에 닿습니다.
- 여름 저녁에는 베가·데네브·알타이르가 여름철 대삼각형을 이룹니다.
- 겨울 저녁에는 오리온자리 삼태성을 남동쪽으로 늘이면 시리우스, 북서쪽으로 늘이면 알데바란에 닿습니다.
- 가을 저녁에는 페가수스 사각형에서 북동쪽으로 안드로메다자리 별을 따라가 M31을 찾습니다.

망원경으로 희미한 대상을 찾을 때는 별 따라가기(star hopping)를 씁니다. 저배율 접안렌즈(40mm 또는 32mm)로 밝은 기준별을 시야에 넣고, 성도에서 확인한 별 무늬를 따라 한 시야씩 옮겨 간 뒤, 찾으면 배율을 올립니다. 천상에서도 같은 순서가 편하며, 찾은 천체는 추적 고정(6.4절)해 두고 배율을 올립니다.

직접 찾는 연습을 할 때는 `/cfind <이름>`의 방향 화살표만 쓰고, 시간이 없을 때는 `/cfind <이름> true`로 시점을 바로 돌립니다. 찾을 수 있는 이름의 형식은 7.1절 표에 있습니다.

#### A.3.4 천상열차분야지도 별자리

천상열차분야지도(天象列次分野之圖)는 조선 태조 때 돌에 새긴 천문도로, 하늘을 삼원(三垣)과 28수(二十八宿)로 나눕니다. 삼원은 북극 둘레의 자미원(紫微垣), 사자자리·처녀자리 부근의 태미원(太微垣), 뱀주인자리·헤르쿨레스자리 부근의 천시원(天市垣)입니다. 28수는 달이 하루에 하나씩 머문다고 여긴 황도·적도 부근의 구역입니다.

설정 화면의 "별자리" 항목을 "천상열차분야지도"로 바꾸면 망원경 화면에 보천가(步天歌) 체계의 별자리 289개가 선과 이름으로 표시됩니다. 영어 화면에서는 로마자(예: 북두 Bukdu)로 나옵니다. 같은 하늘을 서양 88 별자리와 번갈아 보면 같은 별이 두 문화에서 어떻게 묶였는지 비교할 수 있습니다. 예를 들어 북두칠성은 서양에서는 큰곰자리의 일부이고 천상열차에서는 독립된 별자리 북두입니다. 노인성(老人星)은 서양의 용골자리 카노푸스입니다.

### A.4 대상별 관측 요령

#### A.4.1 달

달은 보름보다 상현·하현 무렵에 관측하는 편이 좋습니다. 빛과 그림자의 경계선인 명암 경계선(terminator) 부근에서 크레이터와 산맥의 그림자가 길게 드리워져 지형이 입체적으로 보입니다. 보름에는 정면에서 빛을 받아 그림자가 거의 없고, 대신 티코(Tycho) 같은 크레이터에서 뻗어 나온 밝은 광조(ray)가 잘 보입니다.

천상의 달은 NASA LRO 지도를 쓰며, 확대할수록 해상도가 높아집니다(2.3절). 광학 칭동(libration)이 반영되어 날마다 가장자리 지형이 조금씩 드러나거나 숨습니다. 달 지명 787곳(IAU)을 `/cfind 고요의 바다`나 `/cfind Tycho`로 찾을 수 있습니다. 초승달이나 그믐달 무렵에는 어두운 부분이 지구에서 반사된 빛으로 희미하게 보이는 지구조(earthshine)도 관찰할 수 있습니다.

달의 겉보기 지름은 근지점과 원지점에서 약 14% 차이 나므로, 여러 날 정보 카드의 지름 값을 기록해 비교할 수 있습니다.

#### A.4.2 행성

행성은 표면 밝기가 높아 달이 밝거나 하늘이 조금 밝아도 관측할 수 있습니다. 세부는 시상이 허락하는 한 높은 배율(출사동 0.5\~1mm)에서 보입니다.

| 대상 | 관측 요령 |
| --- | --- |
| 수성 | 해에서 최대 약 28°까지만 떨어지므로 해 진 직후 서쪽 하늘이나 해 뜨기 전 동쪽 하늘의 박명 속에서 낮게 보임. 이각이 가장 클 때를 `/cwhen 수성`으로 찾음 |

#### A.4.3 이중성과 변광성

이중성(double star)은 구경과 분해능을 확인하기에 좋은 대상입니다. 색 대비가 있는 쌍(백조자리 알비레오, 안드로메다자리 알마크)은 저배율에서도 보기 좋고, 간격이 좁은 쌍은 구경 비교 실습에 씁니다.

| 대상 | 간격 | 특징 |
| --- | --- | --- |
| 미자르 (큰곰자리 ζ) | 14.4″ | 소형 망원경으로 쉽게 분리. 맨눈으로 보이는 알코르와는 별개 |
| 카스토르 (쌍둥이자리 α) | 5.4″ | 1.93등과 2.97등 |
| 처녀자리 γ (포리마) | 3.4″ | 비슷한 밝기의 쌍 |
| 거문고자리 ε | 2.1″ / 2.4″ | 저배율에서 두 별, 고배율에서 각각이 다시 둘로 갈라지는 "더블더블" |
| 시리우스 B | 11.1″ | 간격은 넓지만 주성이 매우 밝아 어려운 대상 |

변광성 가운데 알골(페르세우스자리 β)은 식쌍성으로 2.8673일마다 약 10시간 동안 2.1등에서 3.4등으로 어두워집니다. 미라(고래자리 ο)는 약 332일 주기로 3.4등에서 9.3등 사이를 오갑니다. 실제 관측에서는 밝기를 아는 주변 비교성과 견주어 등급을 어림합니다.

#### A.4.4 성단

산개성단(open cluster)은 수십\~수백 개의 젊은 별이 느슨하게 모인 무리로, 넓은 시야의 저배율이 알맞습니다. 천상의 산개성단 둘레는 Gaia DR3의 실제 구성 별로 채워져 있습니다. 플레이아데스(M45)는 맨눈으로, 프레세페(M44)와 페르세우스자리 이중성단(C14)은 쌍안경 수준의 저배율로 보기 좋습니다.

구상성단(globular cluster)은 수십만 개의 늙은 별이 공 모양으로 빽빽이 모인 천체입니다. 작은 구경에서는 중심이 밝은 둥근 빛 얼룩으로 보이고, 구경이 커질수록 가장자리부터 개별 별로 분해됩니다. 천상은 구상성단을 King 분포로 그리고, 13개 성단에는 Harris 목록의 실측 핵 반지름을 씁니다. 그 결과 47 Tuc(C106)은 중심이 뾰족하고, ω Cen(C80)과 M22는 넓적하게 보입니다.

#### A.4.5 성운

발광성운(emission nebula)은 뜨거운 별 둘레의 기체가 빛을 내는 천체입니다. 사진에서는 수소 알파선(656 nm)의 붉은빛이 두드러지지만, 어둠에 적응한 사람 눈은 붉은빛에 둔감하고 청록색(산소 [O III] 501 nm, 수소 베타 486 nm)에 민감해 성운이 회색이나 옅은 청록빛으로 보입니다. 천상의 성운 스케치는 이 특성을 반영해 DSS 청색 사진을 위주로 만들었습니다. M42 오리온 대성운 가운데의 트라페지움 성단은 카탈로그 별로 그려집니다.

행성상성운(planetary nebula)은 죽어 가는 별이 벗어 던진 기체 껍질입니다. 작고 표면 밝기가 비교적 높아 배율을 올려도 잘 견딥니다. M57 고리성운은 중간 배율에서 고리 모양이, M27 아령성운은 저배율에서 사과 속 같은 모양이 보입니다. M97 올빼미성운에서는 두 개의 어두운 "눈"이 보입니다.

성운과 은하는 표면 밝기가 낮으므로 달 없는 어둠 시간, 빛공해가 적은 곳, 충분한 암적응이 모두 필요합니다. 표면 밝기가 낮은 면광원은 사람 눈의 간상세포 특성에 맞춰 색이 빠진 회색으로 그려집니다.

#### A.4.6 은하

은하는 대부분 매우 희미해 가장 밝은 중심부만 보이는 경우가 많습니다. 은하가 얼마나 보이는지는 구경, 배율(출사동), 하늘 밝기가 함께 정합니다. 천상은 은하 341개를 접안렌즈로 본 모습(관측 스케치)으로 그립니다. 바탕은 실제 하늘 사진(DSS2 적색, 339개)이고, 사진이 없는 은하는 허블 형태에 따라 그립니다. 보이는 밝기 문턱보다 밝은 부분만 회색으로 드러납니다.

- 작은 구경과 밝은 하늘: 가운데 얼룩만 보입니다.
- 큰 구경과 어두운 하늘: 원반이 넓게 보이고, 나선팔·막대·먼지띠·덩어리 같은 구조가 드러납니다.

M31 안드로메다은하와 M33 삼각형자리은하는 맨눈에서도 같은 방식으로 보입니다. M31은 매우 크므로 저배율로 전체를 보는 편이 좋고, M51 소용돌이은하는 큰 구경과 어두운 하늘에서 나선팔과 동반 은하 사이의 연결이 드러납니다. M104 솜브레로은하나 옆으로 누운 은하에서는 암흑대를 찾아봅니다.

### A.5 천문 현상 예보와 관측

#### A.5.1 관측 계획 세우기

관측 계획은 `/cwhen`의 오늘 밤 요약과 `/cwhen <천체>`의 가장 좋은 밤 찾기로 세웁니다(문법과 결과 항목은 7.1절). 이 예보는 빛공해와 날씨를 고려하지 않으므로, 실제 관측지의 Bortle 값은 `/cwhen` 첫 줄에서 따로 확인합니다.

#### A.5.2 일식

일식은 달이 해를 가리는 현상으로, 삭(朔) 무렵에 달이 해와 같은 방향에 정확히 놓일 때만 일어납니다. 달 그림자가 지구에 닿는 좁은 띠 안에서만 개기일식(또는 금환일식)이 보이고, 그 바깥 넓은 지역에서는 부분일식이 보입니다. 달이 지구에서 멀어 해를 다 가리지 못하면 금환일식이 됩니다.

다음 일식은 `/cwhen solar <종류>`로 찾고, [이동] 버튼으로 관측 위치를 식 최대 지점으로 옮깁니다(7.1절). 새 월드의 기본 날짜 다음 날인 2026-08-12에 개기일식이 있으며, 식 최대 지점은 약 65°N 25°W입니다.

천상에서는 개기일식 동안 하늘과 땅이 어두워지고 밝은 별과 행성, 코로나가 보입니다. 일식은 그 장소에서 실제로 보이는 만큼만 나타납니다.

실제 태양을 관측할 때는 반드시 인증된 태양 필터를 대물렌즈 앞에 씌워야 합니다. 필터 없이 망원경이나 쌍안경으로 해를 보면 순간적으로 시력을 잃을 수 있습니다. 맨눈 관측도 개기식의 완전히 가려진 시간을 제외하면 일식 안경이 필요합니다. 수업에서는 게임 속 관측과 실제 관측의 이 차이를 반드시 짚어야 합니다.

#### A.5.3 월식

월식은 보름 무렵 달이 지구 그림자에 들어가는 현상입니다. 지구 그림자는 짙은 본영(umbra)과 옅은 반영(penumbra)으로 나뉩니다. 반영월식은 달이 약간 어두워지기만 해서 알아채기 어렵고, 본영에 들어간 부분이 생기면 부분월식, 달 전체가 본영에 들어가면 개기월식입니다. 개기월식 동안 달이 붉게 보이는 것은 지구 대기를 지나며 굴절된 붉은빛이 그림자 안으로 들어가기 때문입니다.

월식은 달이 떠 있는 곳이면 어디서나 같은 시각에 보입니다. 시각과 덮는 비율은 `/cwhen lunar <종류>`로 확인합니다(7.1절). 새 월드에서는 2026-08-28에 부분월식이 있습니다. 월식은 맨눈으로 안전하게 볼 수 있습니다.

#### A.5.4 유성우

유성우는 혜성이 남긴 먼지 띠를 지구가 지날 때 생깁니다. 유성은 하늘의 한 점, 복사점(radiant)에서 퍼져 나오는 것처럼 보입니다. 유성우의 세기는 천정 시간당 유성 수(ZHR)로 나타냅니다. ZHR은 복사점이 천정에 있고 한계등급이 6.5등인 이상적인 하늘에서 한 사람이 한 시간에 볼 수 있는 수입니다. 실제로 보이는 수는 복사점 고도와 하늘 밝기에 따라 줄어듭니다.

천상의 시간당 예상 수는 ZHR × sin(복사점 고도) × 달빛 보정으로 계산합니다. 유성은 극대일, 복사점 고도, 달빛, 비에 따라 양이 바뀌고, 그 밖에 산발 유성이 시간당 10개 나타납니다. 유성은 게임 시각의 압축률과 관계없이 컴퓨터 시계를 따라 흐릅니다(10.1절).

| 유성우 | 약호 | ZHR | 극대 무렵 | 모혜성 |
| --- | --- | --- | --- | --- |
| 사분의자리 | QUA | 110 | 1월 초 | 소행성 2003 EH1 |
| 거문고자리 | LYR | 18 | 4월 하순 | 대처 혜성 (C/1861 G1) |
| 물병자리 에타 | ETA | 50 | 5월 초 | 핼리 혜성 |
| 페르세우스자리 | PER | 100 | 8월 중순 | 스위프트-터틀 혜성 |
| 오리온자리 | ORI | 20 | 10월 하순 | 핼리 혜성 |
| 사자자리 | LEO | 15 | 11월 중순 | 템펠-터틀 혜성 |

다음 극대는 `/cwhen meteor [이름]`으로 찾습니다. 내 위치에서 복사점이 낮으면 더 좋은 장소와 [이동] 버튼이 붙습니다. 유성우 관측에는 망원경이 필요 없습니다. 넓은 하늘이 트인 곳에서 복사점에서 40\~60° 떨어진 하늘을 바라보는 것이 실제 관측의 요령입니다.

#### A.5.5 오로라

오로라는 태양풍의 하전 입자가 지구 자기장을 따라 극지방 상층 대기로 들어와 산소·질소를 들뜨게 할 때 생깁니다. 높이 약 100\~150 km의 산소 원자가 내는 557.7 nm 초록빛이 가장 흔하고, 더 높은 곳(약 200 km 이상)의 산소는 630 nm 붉은빛을 냅니다. 오로라는 자기극을 둘러싼 고리 모양 띠(오로라 타원)에서 주로 나타납니다.

천상의 오로라는 위도 60°가 넘는 곳(남·북)의 밤(해 고도 −10° 아래)에 나타나며, 67\~75°에서 가장 셉니다. 태양 활동의 세기는 밤마다 무작위로 정해집니다. 높이 80\~320 km의 오로라 층을 따라 아래는 초록, 위로 갈수록 붉게 그려집니다. 오로라 띠의 위치는 위도 69° − 3° × 세기이며, 관측자가 띠보다 적도 쪽에 있으면 극 쪽 하늘에서, 띠 아래에 있으면 머리 위에서, 띠보다 극 쪽에 있으면 적도 쪽 하늘에서 보입니다. 달빛이 밝으면 약해지고 망원경 배율이 오르면 옅어집니다.

오로라는 맨눈으로 넓은 하늘을 보는 것이 좋습니다. `/cplace 70 20`(노르웨이 북부 부근)이나 `/cplace longyearbyen`, 남반구 `/cplace mcmurdo`로 관측 위치를 옮겨 여러 밤 기다립니다.

#### A.5.6 황도광과 대일조

황도광(zodiacal light)은 행성 사이 먼지가 햇빛을 산란해 생기는 희미한 빛 기둥으로, 황도를 따라 지평선에서 비스듬히 솟습니다. 북반구 중위도에서는 황도가 지평선과 큰 각을 이루는 봄철 해 진 뒤 서쪽 하늘과 가을철 해 뜨기 전 동쪽 하늘에서 잘 보입니다. 대일조(gegenschein)는 해의 정반대 방향에 보이는 더 희미한 빛 얼룩입니다.

천상에서는 해가 −15° 아래이고 달이 없으며 Bortle 4 아래인 아주 어두운 하늘에서만 나타납니다.

#### A.5.7 그 밖의 예보

보름·삭·행성 근접 예보는 `/cwhen full`, `new`, `conj`, `next`로 확인합니다(7.1절). 삭 무렵은 심원천체 관측에 가장 좋은 시기입니다. 행성 근접은 두 행성이 같은 저배율 시야에 들어오는 드문 기회입니다. 달 원판 뒤의 별·행성·위성은 그려지지 않으므로 달에 의한 엄폐(occultation)도 계산된 위치에 따라 나타나지만, 엄폐 자체를 예보하는 기능은 없습니다.

### A.6 계절별 관측 대상

아래 표는 북위 35\~40° 부근(서울은 37.6°N)에서 각 계절 저녁 9시 무렵 높이 뜨는 대상을 기준으로 했습니다. 관측 위치는 `/cplace seoul`이나 `/cplace 37.6 127.0`처럼 옮깁니다. 표의 대상은 모두 `/cfind`로 찾을 수 있습니다.

### A.8 관측 실습 과제

각 과제는 싱글플레이(치트 허용 월드) 또는 교사가 OP 권한을 가진 서버를 기준으로 합니다. 날짜를 옮기는 `/cele set`과 하늘 속도를 바꾸는 `/cele rate`는 OP 명령입니다(7.2절). 기본 압축률 1.0에서는 마인크래프트 하루(20분)에 하늘도 하루가 흐릅니다.

#### 과제 1. 목성 위성 추적과 목성 질량 구하기

목표: 갈릴레이 위성의 위치 변화를 기록해 공전 주기를 구하고, 케플러 제3법칙으로 목성의 질량을 어림합니다.

1. `/cwhen 목성`으로 목성이 잘 보이는 밤을 찾고, OP라면 [이동]으로 그 날짜·시각으로 갑니다.
2. `/cfind 목성 true`로 망원경을 목성에 고정하고 ×100 안팎으로 배율을 맞춥니다.
3. 위성 하나(예: 이오)를 화면 가운데에 두고 좌클릭으로 선택한 다음, 목성을 가운데에 두고 Ctrl + 좌클릭으로 둘 사이의 각거리를 잽니다. 위성이 목성의 동쪽인지 서쪽인지도 적습니다.
4. 같은 측정을 게임 시각으로 일정한 간격(예: 마인크래프트 시각 2시간)마다 반복합니다. 목성 카드에서 지구까지 거리도 함께 적습니다.
5. 각거리를 시간에 대해 그래프로 그립니다. 사인 곡선이 되며, 한 주기가 공전 주기, 최대 각거리가 궤도 반지름에 해당합니다.
6. 궤도 반지름 a = 지구-목성 거리 × 최대 각거리(라디안)로 구한 뒤, M = 4π²a³ / (G T²)에 넣어 목성 질량을 계산합니다.

참고값: 실제 공전 주기는 이오 1.769일, 유로파 3.551일, 가니메데 7.155일, 칼리스토 16.69일이고, 목성 질량은 약 1.90 × 10²⁷ kg입니다. 위성이 목성 뒤로 들어가면 "현재 가려짐"으로 표시됩니다.

토론 주제: 1610년 갈릴레이가 같은 관측으로 무엇을 주장했는지, 측정 오차는 어디서 생기는지.

#### 과제 2. 금성의 위상과 겉보기 지름

목표: 금성의 위상과 겉보기 지름이 함께 변하는 것을 관측하고, 태양중심설의 근거를 확인합니다.

1. `/cwhen 금성`으로 금성이 저녁 하늘(동방 최대이각 무렵)에 있는 날짜를 찾습니다.
2. 금성을 ×100 이상으로 보고, 카드의 위상(밝은 비율), 지름, 해와의 각거리, 등급을 적습니다.
3. `/cele set`으로 2\~3주 간격으로 날짜를 옮기며 내합(해와 같은 방향) 직전까지 반복합니다.
4. 위상과 지름을 표와 그래프로 정리합니다. 위상이 가늘어질수록 지름이 커지는 관계를 확인합니다.

관찰 요점: 금성은 지구에 가까울 때 초승달처럼 가늘고 크며, 멀 때 둥글고 작습니다. 실제 겉보기 지름은 약 10″에서 60″ 이상까지 변합니다. 지구중심설(프톨레마이오스 체계)에서는 금성이 항상 해보다 가까이 있어 둥근 위상이 나타날 수 없다는 점을 토론합니다.

확장: 같은 방법으로 수성의 위상을 관측해 보고, 수성이 박명 속에서만 보이는 이유를 최대이각과 연결합니다.

#### 과제 3. M13 구경 비교

목표: 같은 대상을 여러 구경으로 비교해 집광력과 분해능의 효과를 확인합니다.

1. 여름 저녁 M13(헤르쿨레스자리 구상성단)이 높이 뜬 시각을 `/cwhen M13`으로 찾습니다. 달이 없는 밤을 고릅니다.
2. 빛공해가 적은 곳(Bortle 값이 낮은 곳)에서 `/cfind M13 true`로 고정합니다.
3. 배율을 비슷하게 맞추어 네 구경을 비교합니다.

| 구경 | 접안렌즈 | 배율 | 출사동 |
| --- | --- | --- | --- |
| 50mm | 5mm | ×70 | 0.7mm |
| 80mm | 9mm | ×62 | 1.3mm |
| 127mm | 15mm | ×59 | 2.1mm |
| 305mm | 32mm | ×67 | 4.6mm |

4. 각 구경에서 보이는 모습(빛 얼룩의 크기, 중심 집중도, 개별 별이 보이는 범위)을 스케치합니다. 화면 안의 가장 어두운 별을 좌클릭해 등급을 확인하고 그 구경의 한계등급(6.2절)과 비교합니다.
5. 같은 실험을 보름달 밤이나 마을 옆에서 반복해 하늘 밝기의 영향을 비교합니다.

관찰 요점: 50mm에서는 중심부의 희미한 빛 얼룩으로만 보이고, 305mm에서는 바깥쪽부터 개별 별이 분해됩니다. 배율이 같아도 출사동이 커지면 표면 밝기가 높아진다는 점, 구경이 커지면 더 어두운 별까지 보인다는 점을 함께 정리합니다.

#### 과제 4. 이중성으로 분해능 확인

목표: 분해능이 구경에 반비례함을 확인합니다.

1. 거문고자리 ε(`/cfind 거문고자리 ε true`)을 고릅니다.
2. 저배율에서 두 별로 갈라지는 것을 확인한 뒤, 구경 50mm부터 차례로 올리며 각 쌍(2.1″, 2.4″)이 다시 둘로 갈라지는 최소 구경을 찾습니다. 배율은 ×100 이상으로 둡니다.
3. 같은 방법으로 카스토르(5.4″), 처녀자리 γ(3.4″)를 측정합니다.
4. 측정한 최소 구경을 레일리 기준 138″/D, 도스 한계 116″/D로 계산한 값과 비교합니다.

토론 주제: 실제 관측에서 큰 구경의 분해능이 이론값에 못 미치는 이유(시상), 천상에서 시상이 1.5″로 고정되어 있다는 점이 결과에 나타나는 방식.

#### 과제 5. 빛공해와 맨눈 한계등급

목표: 하늘 밝기가 보이는 별의 수에 미치는 영향을 측정합니다.

1. 횃불이 많은 마을 한가운데, 마을에서 32블록 떨어진 곳, 광원이 없는 64블록 밖 언덕 세 곳을 관측 지점으로 정합니다.
2. 지점마다 `/cwhen` 첫 줄의 Bortle 값을 적습니다.
3. 같은 별자리(예: 작은곰자리)를 ×1로 보며 보이는 가장 어두운 별을 좌클릭해 등급을 적습니다.
4. 같은 측정을 보름달 밤과 그믐 밤에 반복합니다.
5. Bortle 값, 달 위상과 맨눈 한계등급의 관계를 표로 정리하고 A.1.2절의 Bortle 표와 비교합니다.

확장: 관측 직전 횃불을 들고 있다가 내려놓은 경우와 어둠 속에서 기다린 경우를 비교해 암적응의 효과를 확인합니다.

#### 과제 6. 알골의 광도곡선

목표: 식쌍성의 밝기 변화를 측정해 주기를 구합니다.

1. `/cfind 알골`로 알골을 찾고 카드의 등급을 읽습니다.
2. 게임 시각으로 1시간 간격으로 등급을 기록합니다. 압축률 1에서 알골의 주기(2.8673일)는 마인크래프트 시각 약 2.9일, 실제 시간 약 1시간입니다.
3. 시간-등급 그래프를 그려 극소 시각, 극소 지속 시간, 주기를 구합니다.

관찰 요점: 밝기가 일정하다가 약 10시간 동안 2.1등에서 3.4등으로 어두워졌다가 돌아옵니다. 어두운 동반성이 밝은 주성을 가리는 식쌍성 모델로 설명합니다.

### A.9 모델의 범위

천상의 관측 결과는 계산 모델에 의한 시뮬레이션이며, 모델의 단순화와 정확도는 12절에 정리되어 있습니다. 수업에서는 그 가운데 다음 차이를 함께 다루는 것이 좋습니다.

- 하늘 밝기는 천정 한 점의 값을 하늘 전체에 적용하므로, 지평선 쪽 빛공해 돔이나 달 근처의 밝음이 방향별 한계등급에 반영되지 않습니다.
- 암적응 회복은 30초로 실제(20\~30분)보다 짧습니다.
- 관측자 개인차는 맨눈 한계등급 설정(4\~6.5)으로만 반영됩니다.
- 15.2등보다 어두운 별은 개별 별로 그려지지 않고 은하수 영상에만 포함됩니다.
- 실제 태양 관측에는 반드시 전용 태양 필터가 필요합니다.
